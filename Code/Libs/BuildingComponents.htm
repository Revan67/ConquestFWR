How To Build DA Library Components

Note: In the discussion below, it is assumed that you have a directory tree on your machine that mirrors the tree in Source Safe. The root of that tree is referred to as "&\".

  1. Get the source code via Source Safe. The source lives in the $/libs/dev/src tree.
  2. Set the file &\Libs\Dev\Src\BuildRes.h to read-write.
  3. Uncomment the line which defines the OFFICIAL_BUILD macro if this is to be a published build.
  4. Perform a clean build of the component.
  5. Check out the component to make sure the build worked.
  6. If all is well, label the entire $/libs/dev/src tree with the name of the component and its current version (stored in XXXVer.h, where XXX is the name of the component). Static libraries do not have version header files.
  7. Check out all the related header files in $/libs/published/include.
  8. Copy all the related header files from &\libs\dev\include to &\libs\published\include.
  9. Check in the related header files from $/libs/published/include.
  10. Label all the headers in $/libs/published/include with the name of the component and its current version number.
  11. Check out the component in $/libs/published/{ExplicitDLL,ImplicitDLL,Static}.
  12. Copy the new component from its compiled directory to &\libs\published\{ExplicitDLL,ImplicitDLL,Static}.
  13. Check in the component in $/libs/published/{ExplicitDLL,ImplicitDLL,Static}.
  14. Label the component in $/libs/published/{ExplicitDLL,ImplicitDLL,Static} with the component name and current version number.
  15. Check out the component version header file.
  16. Increment the version minor number. NOTE: This is done after the component is published so that subsequent compilations will have an advanced version number.
  17. Check in the component version header file.
  18. Re-get $/libs/dev/src/BuildRes.h from Source Safe, ensuring that subsequent builds are not accidentally marked as official.

 

Due to the large number of steps in the process, most of which must be repeated for each component, this process is a prime candidate for automation.
